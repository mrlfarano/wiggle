🏗️ Solution Architecture

Runtime-verified Compile-verified (env-aware) WinUI 3 frontend

ScreenStudio.App — WinUI 3 frontend (NEW)

RecordingOverlay (tray + REC + transport) · PostRecordWindow (preview + ExportSheet) · StylePanel (cursor/smoothing/zoom/aspect) · TimelinePanel (keyframe editor) · SettingsWindow (persistence) · 6 ViewModels (INPC wrappers over the engine) · TrayController (Win32 Shell_NotifyIcon) · WindowEnumeration (EnumWindows)

ScreenStudio.Core — engine + DSP (headless, 86 tests)

CursorSmoother (centripetal Catmull-Rom) · ZoomDetector + ZoomCamera (ease cubic) · FrameCompositor (RGB32 zoom+cursor) · RecordingTimeline (trim/cut/keyframe) · ExportPipeline (progress/cancel) · Audio DSP: NoiseGate + LevelMeter + AudioMixer + AudioExportMixer · AspectRatioConverter · CursorEventLogger + RecordingSession · ExportSettingsViewModel + ConsoleUi

ScreenStudio.Native — Windows 11 media integration

● FfmpegScreenCapture (gdigrab) · ● FfmpegEncoder (libx264 → real MP4) · ● FfmpegAudioCapture (dshow mic) · ○ WindowsScreenCapture (WGC) · ○ MediaFoundationEncoder (MF sink writer) · ○ WindowsAudioCapture (AudioGraph/WASAPI) · CursorHook (WH_MOUSE_LL)

🛠️ Tech Stack

Language / Runtime: C# / .NET 10

UI: WinUI 3 (Windows App SDK 2.3.1) — builds without VS via the maui-windows workload

Native media: Windows Graphics Capture · Media Foundation · WASAPI (WinRT projection, net10.0-windows10.0.19041.0)

Runtime capture/encode: FFmpeg 7.1.1 — gdigrab (screen) · libx264 (H.264) · dshow (audio)

Testing: xUnit · 154 tests (incl. 14 PRD-based user-feature tests) · 0 errors
