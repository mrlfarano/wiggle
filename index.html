// features
what it does automatically
@media(max-width:768px){grid-template-columns:1fr}

// capture

  • Full screen, window, or region at up to 60fps
  • Microphone + system audio via WASAPI loopback
  • Webcam picture-in-picture overlay
  • Keyboard shortcut display (keycap overlay)
  • Cursor tracking via WH_MOUSE_LL + QPC timestamps

// effects

  • Auto-zoom on clicks, drags, pauses with ease-in/out
  • Cursor smoothing (centripetal Catmull-Rom, 4 intensities)
  • Motion blur trail based on cursor velocity
  • Background, padding, shadow, border styling

// audio

  • Noise gate (threshold / hysteresis / attack / release)
  • Peak + RMS normalization
  • Multi-track mixing with soft-clip
  • Level meters with dBFS readout

// export

  • H.264 / HEVC MP4 (NVENC/QSV/AMF hardware encode)
  • GIF (two-pass palette pipeline)
  • WebM (VP9)
  • Aspect presets: 16:9, 9:16, TikTok, Reels, Shorts
  • Timeline: trim, cut, speed ramp, zoom keyframe editing
