capabilities
what it does, automatically

capture

  • Full screen, window, or region up to 60fps
  • Mic + system audio via WASAPI loopback
  • Webcam picture-in-picture overlay
  • Keyboard shortcut display (keycap overlay)

effects

  • Auto-zoom on clicks, drags, pauses
  • Cursor smoothing (Catmull-Rom, 4 levels)
  • Motion blur trail
  • Background, padding, shadow, border

audio

  • Noise gate (threshold / attack / release)
  • Peak + RMS normalization
  • Multi-track mixing with soft-clip
  • Level meters with dBFS

export

  • H.264 / HEVC MP4 (NVENC/QSV/AMF)
  • GIF (two-pass palette)
  • WebM (VP9)
  • Trim, cut, speed ramp, zoom keyframes
